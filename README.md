# AI Gym Trainer (Zoro AI Trainer)

A personal AI fitness-training web application combining intelligent workout planning, scheduling, real-time exercise guidance, progress tracking, and interactive motivation.

## 🚀 Features

- **AI Fitness Coach**: Personalized workout recommendations and dynamic exercise plans.
- **Workout Dashboard & Tracking**: Visual calendar, streak tracking, workout logging, and completion history.
- **Modern Dark UI**: Aesthetic dark interface with sleek emerald accents, glassmorphic cards, and responsive navigation.
- **Progress Analytics**: Track body metrics, workout volume, streaks, and personal records.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Backend / Auth**: Supabase (PostgreSQL, Row-Level Security, Auth)

## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Elangumaran05/AI-gym-trainer.git
   cd AI-gym-trainer
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the app.
